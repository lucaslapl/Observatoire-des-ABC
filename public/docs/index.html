Introduction

API publique en lecture seule de l'Observatoire des ABC : projets ABC, communes, départements, régions, journal d'audit et statistiques. Données sous Licence Ouverte 2.0 (Etalab). Accès ouvert sans clé, 60 requêtes/min par IP.

Base URL: http://localhost:8000 
## Réutilisation et crédit

Toutes les données exposées (sources agrégées + enrichissements des
contributeurs) sont réutilisables sous
[Licence Ouverte 2.0 (Etalab)](https://www.etalab.gouv.fr/wp-content/uploads/2017/04/ETALAB-Licence-Ouverte-v2.0.pdf).
Le crédit attendu, prêt à copier :

> Source : Observatoire des ABC (observatoire-abc.fr), enrichi par ses
> contributeurs, d'après les données de l'OFB et du Fonds vert — sous
> Licence Ouverte Etalab 2.0. Mise à jour : [date].

## Limites d'usage

- Aucune garantie sur les données (exactitude, complétude, disponibilité).
- La mention de crédit ne confère aucun caractère officiel et ne doit pas
suggérer un cautionnement par l'Observatoire, l'OFB ou le Fonds vert.
- Accès ouvert sans clé : **60 requêtes/min par IP** (throttling) ;
chaque réponse GET est en cache avec `ETag` + `Cache-Control`
(reprenez le `304` quand rien n'a changé).
- Pagination **par curseur** : suivez `meta.next_cursor` /
`meta.next_page_url` — jamais de pagination par offset.
- Versionnement : `v1` est figée, aucun breaking change dans une
version publiée ; les évolutions arrivent en `v2`.

Authenticating requests

This API is not authenticated.

Communes

Fiche d'une commune : localisation, EPCI, projets liés (avec provenance de chaque projet). Format GeoJSON avec `format=geojson` ou `Accept: application/geo+json` (une feature par projet lié).

Example request:
curl --request GET \
    --get "http://localhost:8000/api/v1/communes/architecto" \
    --header "Content-Type: application/json" \
    --header "Accept: application/json" \
    --data "{
    \"format\": \"geojson\"
}"

const url = new URL(
    "http://localhost:8000/api/v1/communes/architecto"
);

const headers = {
    "Content-Type": "application/json",
    "Accept": "application/json",
};

let body = {
    "format": "geojson"
};

fetch(url, {
    method: "GET",
    headers,
    body: JSON.stringify(body),
}).then(response => response.json());

Projets

Liste des projets ABC.

Paginée par curseur (meta.next_cursor / meta.next_page_url). Filtres : statut (a_venir, en_cours, termine, inconnu — statut affiché, le verdict de vérification prime), annee (année de début), code_insee, departement (ex. 56, 2a, 972), region (slug, code INSEE ou libellé), porteur (recherche partielle), bbox (lon_min,lat_min,lon_max,lat_max, WGS84). Format GeoJSON avec format=geojson ou Accept: application/geo+json.

Example request:
curl --request GET \
    --get "http://localhost:8000/api/v1/projets" \
    --header "Content-Type: application/json" \
    --header "Accept: application/json" \
    --data "{
    \"statut\": \"en_cours\",
    \"annee\": 1,
    \"code_insee\": \"T8GOX$\\/i\",
    \"departement\": \"b\",
    \"region\": \"m\",
    \"porteur\": \"i\",
    \"bbox\": \"8,sssssss-20:.492,ssssss-1,ssss9\",
    \"per_page\": 3,
    \"format\": \"json\"
}"

const url = new URL(
    "http://localhost:8000/api/v1/projets"
);

const headers = {
    "Content-Type": "application/json",
    "Accept": "application/json",
};

let body = {
    "statut": "en_cours",
    "annee": 1,
    "code_insee": "T8GOX$\/i",
    "departement": "b",
    "region": "m",
    "porteur": "i",
    "bbox": "8,sssssss-20:.492,ssssss-1,ssss9",
    "per_page": 3,
    "format": "json"
};

fetch(url, {
    method: "GET",
    headers,
    body: JSON.stringify(body),
}).then(response => response.json());
